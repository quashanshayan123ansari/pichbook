## Getting Started

### 1. Prerequisites
- **Node.js** v18.17.0+ or v20+
- **Python** 3.10+
- **Git**

### 2. Clone the Repository
```bash
git clone https://github.com/aryanRN2/pichbook.git
cd pichbook
```

### 3. Run the Financial Computation Engine
Execute the standalone Python verification script to audit multiples, reconciliations, and DCF calculations:
```bash
python3 atlas_compute.py
```
*Expected result:* All 6 EV bridge checks pass with zero reconciliation variance.

### 4. Regenerate the Excel Data Pack
Re-generate the formatted Excel file (`ATLAS_DataPack.xlsx`):
```bash
python3 -m pip install openpyxl
python3 atlas_excel.py
```

### 5. Launch the Interactive Next.js Dashboard
Navigate to the `dashboard/` directory and run the local development server:
```bash
cd dashboard
npm install
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

To produce a production-ready optimized build:
```bash
npm run build
npm start
```

## Model Audit & Mathematical Integrity

The financial engine implements strict reconciliation tests ensuring institutional reliability:
1. **EV Bridge Verification:** $\text{Market Cap} + \text{Total Debt} - \text{Cash} = \text{EV}$ validated for ATLAS and all 5 peer companies.
2. **Share Count Reconciliation:** $\text{Share Price} \times \text{Diluted Shares} \equiv \text{Reported Market Cap}$ reconciled across all entities.
3. **DCF Sensitivity Convergence:** Mathematical reconciliation of Gordon Growth Terminal Value and base case parity against grid coordinates $(\text{WACC}=12\%, g=5.5\%)$.

Audit logs are stored in [`atlas_output.txt`](atlas_output.txt).
